# 制作機能

一つの会話で世界観、画風、登場人物、シーンを作成・修正します。キャラは正面を生成し、それを参照して横・背面を生成します。セリフは日本語フォントで合成。用途に合わせた固定レイアウト、PNG・ZIP・無音スライドMP4を書き出せます。確定素材は元を保持した別案として修正します。

画像品質はモデルに依存し、背景の偶発文字、人物差、吹き出しの重なりは確認が必要です。音声入力の対応はブラウザ・OS依存です。

1コマに最大4つの吹き出し、1吹き出し最大120文字を保存・合成できます。長さに応じて文字と吹き出しのサイズを調整します。セリフだけの変更は元画像を使って再合成し、画像生成APIを呼びません。人物の顔との重なりは絵の構図に依存するため、必要に応じて確認・修正してください。
