# ローカル公開版への移行（2026-09-15）

SaaS課金開始を取りやめ、クローンして本人のPCで実行する形式へ変更。--local を追加し、会社の認証・課金・キーへの依存を除去。画風見本を同梱し、クラウド停止後も表示可能にした。

会社の事業計画・運用記録・インフラ識別子・問い合わせ管理情報・過去のGit履歴は公開版に含めない。元データと復元確認済みクラウドバックアップは非公開で保管。

検証結果とAWS撤去結果は docs/release-check.md に記載する。

## ローカル設定画面（2026-09-15）

`--local` ではログイン・表示名・同意画面を省略。設定はAPIキーと実測トークンの累計／最新100件に限定。使用量未取得・処理中の予約値は実測に含めず、内部の所有者情報は保存先の識別にのみ使用。同意記録を自動作成しない。既存の有料プラン情報があってもローカルは本人キーのみを使用。

Python 161テスト成功。既存Chromeで初回登録なしの制作画面、設定画面、登録済みキーの非表示、空の利用履歴を確認。検証で生成APIは呼び出していない。

## 生成の継続許可

生成依頼・継続委任をLLMが解釈し、利用者発言の原文を添えて実行可能にした。通常の確認方式も維持。正面への承認では未生成の横面・背面を一括予約し、既存の正面を保持。停止や修正の意図は継続委任より優先する。自動テストはモックであり、今回の変更のための実API生成は行っていない。

## 生成後の次の行動案内

`generate_images.completion_message` にLLMが文脈に合う次の行動を記述し、画像生成の成功後だけ画像と一緒に履歴保存する。追加の会話API呼び出しは不要。古い予約やメッセージ未指定時も、正面・三面図・漫画の確認案内へフォールバックする。通常の会話にも次の確認・行動を具体的に案内する指示を追加。モック画像生成から案内文の保存までの回帰テストを追加。今回の実API生成は未実施。

## ショート形式の複数コマ表示

ショート形式のscene.outputは最初の1コマの表紙画像であり、チャットの完成画像として使うと残りのコマが見えなかった。ショートは各コマの画像を順番に表示し、ページ・縦読みは従来の合成画像を表示するよう修正。実データで4コマ保存済みを確認し、最新の結果メッセージの画像参照を修復（再生成なし）。166件の自動テスト成功。

## チャットの使い方パネル

制作チャットでは右側に使い方・例文を初期表示。動画（無音MP4）・画像のダウンロード、コマ／セリフの修正、続き、人物追加を案内する。クリックで入力欄へ追記するだけで自動送信しない。素材閲覧時は素材に切り替え、閉じると案内へ戻る。狭い画面では高さ制限付きの一覧にする。Chromeで初期表示と例文入力を確認。生成APIの呼び出しなし。

## 複数吹き出し・長文

nativeツールのpanel.bubblesで最大4件・各120文字を保存。従来の単一text形式は互換。構図プロンプトに全吹き出し領域と話者を渡し、ローカル日本語フォントでサイズ調整して合成。セリフ変更はraw画像を再利用し、対象外コマと固定セリフを保持。169件の自動テスト成功。4吹き出しの合成見本も目視確認。実API生成は未実施。使い方ボタンから素材閲覧を閉じるリンクも修正。

## 素材閲覧時のスクロール・完成コマ閲覧

素材ルートへの切替で先頭へ戻す処理を除去。チャットの素材切替／新着時に最下部へ移動し、遅延画像読み込みによる高さ変化にも追従。ユーザーが過去を読むためにスクロールした場合は追従を解除。完成シーンは各コマの画像を前後矢印で巡回表示し、番号と個別PNG保存を付けた。世界観→4コマのシーン切替後に最下部との差0px、矢印で2コマ目の画像へ切替をChromeで確認。ルーティング・送信ショートカットの既存テスト成功。

## 確定ボタン

世界観の下書き・画像と名前が揃った人物・生成済みシーンの返答に確定ボタンを添付。押下は専用エンドポイントから既存の確定ツールを呼び、追加のLLM／生成APIなしでサイドバーへ反映する。提示したスナップショットのハッシュ、所有者、作品revision、処理中状態を検証。変更後の古いボタン・二重クリックを拒否。チャットのOKによる確定も維持。全体172件と追加の人物再提示防止を含む確認機能4件のテスト成功。
