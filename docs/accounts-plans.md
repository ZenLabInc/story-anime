# ローカルプロフィールとAPIキー

--local ではこのPC用のプロフィールを自動で用意します。メール・Googleログイン・有料プランは不要です。ログイン・表示名登録・同意画面を経由せず制作を開始できます。設定画面には入力／出力トークンの累計と最新100件の履歴を表示し、料金・プラン・利用率は表示しません。未取得の使用量や予約上限は実測の合計に含めません。同意済みの記録を自動作成することもありません。APIキーは設定から登録・変更・削除します。

.local/studio/studio.db に暗号化したキーを保存し、暗号鍵は .local/local-key-encryption に保存します。作品をバックアップする際は .local フォルダ全体を非公開で保管してください。暗号鍵を失うとAPIキーを再登録する必要があります。
